# Version 11.1 — Canvas Lock

This update prevents the artwork from sliding while the customer is trying to paint.

## Default behavior

- The canvas starts locked.
- A normal mouse click, finger tap, or Apple Pencil tap paints.
- Single-finger movement does not pan while the canvas is locked.
- The cursor displays as a painting crosshair.

## Panning

- Select **Pan Canvas** to unlock touch dragging while zoomed in.
- Select **Canvas Locked** again before painting.
- On desktop, hold the Space bar and drag, or use the middle mouse button.
- Mouse painting no longer turns into accidental dragging.

Previously generated artwork must be rebuilt so its interactive player receives
the new interaction behavior.
