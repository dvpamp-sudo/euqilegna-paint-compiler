# Color-by-Number designs

Images in this folder appear as pickable designs in the Color-by-Number demo
(`/beta/color-by-number`), under **More Designs**.

- Drop `PNG`, `JPEG`, or `WebP` files here. The filename becomes the design
  title (`golden-koi.png` → "Golden Koi").
- You can also add a design from the demo itself: **More Designs → Add to
  Design Library** saves the uploaded image into this folder.
- A design is compiled on first open and then cached, so later painters load
  it instantly.

The demo always offers the built-in *Dahlia Mandala* in addition to anything
listed here.
